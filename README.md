# 🕊️ مهدی‌رسان — ربات پیام ناشناس تلگرام

ربات پیام ناشناس با پنل ادمین کامل، لینک اختصاصی ناشناس برای هر کاربر، سیستم VIP و آمار.

## ✨ قابلیت‌ها
- 📩 دریافت پیام ناشناس کاربران توسط ادمین + پاسخ ناشناس
- 🔗 لینک ناشناس اختصاصی پایدار برای هر کاربر (Deep Link با توکن امن تصادفی — بدون آیدی عددی)
- 💎 سطح دسترسی VIP: نمایش اطلاعات فرستنده (یوزرنیم، اسم، آیدی، تعداد پیام) + آمار پیشرفته
- 📊 پنل مدیریت کاربر: آمار امروز / کل + بازدید لینک
- 🛠 پنل ادمین: آمار کلی، مدیریت VIP (افزودن/حذف/لیست/جستجو)، مدیریت کاربران، پیام همگانی، جوین اجباری، چنل فوروارد، بات‌های چندگانه
- 🛡 Rate Limit قابل تنظیم + چک دسترسی در بک‌اند برای همه callbackها

## 🚀 اجرا روی GitHub Actions (24/7)
- Workflow: `.github/workflows/mahdiresan-bot.yml`
- هر اجرا ~۵.۵ ساعت ربات را با حلقه نگهدارنده اجرا می‌کند و در پایان، state را به اجرای بعدی می‌دهد (زنجیره ۲۴/۷).
- State (config + data همه بات‌ها) به‌صورت `base64(tar.gz)` از طریق ورودی workflow_dispatch بین اجراها دست‌به‌دست می‌شود و هرگز داخل ریپو ذخیره نمی‌شود؛ پشتیبان: artifact یک‌روزه + اجرای نجات‌رسان زمان‌بندی‌شده.
- 🔒 هیچ توکن یا secret ای داخل ریپو قرار ندارد.

## اجرای محلی
```bash
pip install -r requirements.txt
python bot.py
```
