# 🕊️ مهدی‌رسان — ربات پیام ناشناس تلگرام

ربات پیام ناشناس با پنل ادمین کامل، لینک اختصاصی ناشناس برای هر کاربر، سیستم VIP و آمار.

## ✨ قابلیت‌ها
- 📩 دریافت پیام ناشناس کاربران توسط ادمین + پاسخ ناشناس
- 🔗 لینک ناشناس اختصاصی پایدار برای هر کاربر (Deep Link با توکن امن تصادفی — بدون آیدی عددی)
- 💎 سطح دسترسی VIP: نمایش اطلاعات فرستنده (یوزرنیم، اسم، آیدی، تعداد پیام) + آمار پیشرفته
- 📊 پنل مدیریت کاربر: آمار امروز / کل + بازدید لینک
- 🛠 پنل ادمین: آمار کلی، مدیریت VIP (افزودن/حذف/لیست/جستجو)، مدیریت کاربران، پیام همگانی، جوین اجباری، چنل فوروارد، بات‌های چندگانه
- 🛡 Rate Limit قابل تنظیم + چک دسترسی در بک‌اند برای همه callbackها

## 🚀 اجرا روی GitHub Actions (24/7)
- Workflow: `.github/workflows/mahdiresan-bot.yml`
- هر اجرا ~۵.۵ ساعت **هر ۳ بات را همزمان** (بات اصلی + ۲ اینستنس) با حلقه نگهدارنده اجرا می‌کند؛ اگر یکی از بات‌ها کرش کند ۱۰ ثانیه بعد دوباره بالا می‌آید.
- در پایان هر شیفت: dispatch زودهنگام اجرای بعدی (تا وقتی شیفت تمام می‌شود، اجرای بعدی از قبل در صف است) → خاموشی تمیز با SIGTERM → state به اجرای بعدی پاس داده می‌شود. وقفه خاموشی به ~۱ تا ۱.۵ دقیقه کاهش یافته.
- ⚙️ قبل از هر خاموشی برنامه‌ریزی‌شده، به ادمینِ همان بات پیام «ربات درحال خالی سازی فضای رم تا چند دقیقه دیگر ربات روشن میشود» فرستاده می‌شود (داخل `bot.py` روی SIGTERM + لایه پشتیبان `scripts/notify_admin.py`).
- State بین اجراها از طریق ورودی `state_b64` دست‌به‌دست می‌شود و هرگز داخل ریپو ذخیره نمی‌شود؛ پشتیبان: artifact دومنه + رسیکو زمان‌بندی‌شده هر ۲۰ دقیقه + heartbeat روزانه (جلوگیری از غیرفعال‌شدن schedule بعد از ۶۰ روز).
- 🔐 بوت‌استرپ از Secrets: اگر state کاملاً گم شود، کانفیگ هر بات از Secret خودش دوباره ساخته می‌شود. Secret های لازم:
  | Secret | بات |
  |---|---|
  | `BOT_TOKEN` / `ADMIN_ID` | بات اصلی |
  | `BOT2_TOKEN` / `BOT2_ADMIN_ID` | اینستنس ۲ |
  | `BOT3_TOKEN` / `BOT3_ADMIN_ID` | اینستنس ۳ |
- 🔒 هیچ توکن یا secret ای داخل ریپو قرار ندارد.

## اجرای محلی
```bash
pip install -r requirements.txt
python bot.py                       # بات اصلی (config.json)
python bot.py --instance NAME      # بات دوم (instances/NAME/config.json)
```
